Privacy Policy & Data Security

1. Data Collection: Global Pathway Mobility collects identity documentation strictly for the purpose of international application processing and auditing.

2. Security Protocols: All submitted files and structural data are secured using industry-standard cryptography. Authentication frameworks ensure data visibility is restricted to the applicant and authorized consulate auditors.

3. Invoice Public Registry: For payment validation, a Reference Code is generated. Querying this code displays non-sensitive application metrics (Name, Status) to establish financial traceability.

4. Retention: Data is purged automatically 90 days after visa culmination or upon explicit written request.
